# HANABI 当前功能式样书（v3.0）

## 1. 项目定位
HANABI 是基于 Next.js、TypeScript、Supabase 与 Cloudflare Stream 的商城及正版影视平台。影片购买与实体商品购物流程彼此独立。

## 2. 全站导航
- 前后台共用置顶导航栏，提供影片、商城、购物车、个人中心、影片管理和商品管理入口。
- 当前页面自动高亮，移动端支持横向滚动。
- 菜单由配置数组维护，便于后续扩展订单和用户管理。

## 3. 影片功能
- 首页仅展示已发布且未软删除的影片。
- 支持免费、会员、单片购买、会员或购买四种观看策略。
- 付费影片在详情页直接创建单片订单，不进入购物车。
- 支持免费试看、播放授权、Cloudflare Stream 签名播放、进度保存和断点续播。
- 影片后台支持创建、编辑、草稿、发布、归档和可恢复软删除。

## 4. 商城功能
- `/shop` 展示已上架、未删除且有库存的商品。
- `/products/[id]` 展示商品详情、价格、库存和加入购物车按钮。
- 商品购物车支持数量调整、移除、合计和本地持久化。
- `/checkout` 支持 Stripe、微信支付、支付宝渠道选择并创建商品订单。
- 服务端以数据库价格和库存为准校验订单，拒绝下架、删除或库存不足的商品。
- 支付完成后更新商品库存；影片订单则发放观看权益。

## 5. 商品管理
- `/admin/products` 支持商品新增、列表和编辑。
- 可维护名称、简介、图片 URL、价格、库存和上架状态。
- 状态包括草稿、已上架和已下架。
- 下架删除采用软删除，保留历史订单，并可通过修改状态恢复。

## 6. 用户、订单与安全
- Supabase 邮箱注册、登录和会话管理。
- 个人中心显示账号、订单、权益和续播记录。
- 管理员通过 `app_metadata.role = admin` 鉴权。
- Webhook 使用签名校验完成订单、发放影片权益或扣减商品库存。
- Service Role Key、支付密钥和 Stream 私钥只能配置在服务端。

## 7. 数据库升级
- 全新环境执行 `supabase/schema.sql`。
- 已有影片环境先执行 `docs/soft-delete-migration.md`。
- 新增商城功能执行 `docs/commerce-migration.md`。

## 8. 管理界面
- 影片表单显示明确标签，价格以元、试看时长以分钟输入并自动换算。
- 影片表单采用四/三/二/一列响应式布局，简介独占整行，操作按钮居中。
- 商品表单采用响应式布局，简介独占整行，创建、保存和软删除按钮居中。

## 9. 尚未实装
- Cloudflare Stream 视频上传和物理删除。
- 各支付平台官方 SDK 的完整生产签名、退款和对账流程。
- 收货地址、物流、运费模板、优惠券和发票。
- 商品多规格 SKU、库存事务锁和超时订单库存释放。
- 跨浏览器 HLS 增强、DRM、水印和并发设备限制。
- 自动化测试、审计日志、监控告警和后台分页搜索。
