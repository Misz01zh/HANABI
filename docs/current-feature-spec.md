# HANABI 当前功能式样书（v2.1）

## 1. 项目定位

HANABI 是基于 Next.js、TypeScript、Supabase 与 Cloudflare Stream 的商城及正版影视播放系统。影片支持免费、会员、单片购买、会员或购买四种观看方式。

## 2. 已实装功能

### 用户与权限
- Supabase 邮箱注册、登录和会话管理。
- 个人中心显示账号、订单、权益和续播记录。
- 管理员通过 `app_metadata.role = admin` 鉴权。

### 商城与订单
- 购物车、结算页和服务端订单创建。
- 支持 Stripe、微信支付、支付宝的支付提供商抽象。
- Webhook 签名校验、订单完成和购买权益发放。
- 订单创建只接受已发布且未删除的付费影片。

### 影视与播放
- 首页影片目录和影片详情页。
- 免费、会员、单片购买、会员或购买四种访问策略。
- 免费试看时长、服务端播放授权与短期签名令牌。
- Cloudflare Stream 签名播放 URL。
- 播放进度保存与断点续播。

### 管理后台
- `/admin/movies` 支持影片新增、列表和编辑。
- 可维护标题、简介、海报、访问策略、价格、试看时长和 Stream UID。
- 影片状态支持草稿、已发布、已归档。
- “下架并删除”采用软删除；可将状态改回草稿或已发布进行恢复。
- 软删除不会删除订单、权益、播放记录或 Cloudflare 原视频。

### 展示规则
- 前台仅展示 `status = published` 且 `deleted_at is null` 的影片。
- 影片详情与订单接口同样拒绝未发布或已归档影片。
- RLS 公共读取策略只允许已发布且未删除的影片。

## 3. 数据库升级

全新环境执行 `supabase/schema.sql`。已有环境按 `docs/soft-delete-migration.md` 执行升级 SQL。升级后历史影片默认为草稿，需要在管理后台手动发布。

## 4. 尚未实装

- Cloudflare Stream 视频上传和物理删除（目前保留原视频，物理删除需人工处理）。
- Stripe、微信支付、支付宝各官方 SDK 的完整生产签名与退款流程。
- 跨浏览器 HLS 播放增强、DRM、水印和并发设备限制。
- 商品库存、物流、优惠券、发票等实体商城能力。
- 自动化测试、审计日志、监控告警与管理后台分页搜索。

## 5. 安全约束

- Service Role Key、支付密钥和 Stream 私钥只能配置在服务端环境变量中。
- 播放权限必须在服务端判断，客户端参数不可信。
- 删除影片默认使用可恢复的软删除，避免破坏历史订单和用户权益。
