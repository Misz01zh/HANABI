# HANABI 当前功能式样书（v0.1）

## 1. 目标

构建“商城 + 正版影片点播”平台，支持会员订阅与单片购买并存；用户获得观看权益后可在线播放影片。

## 2. 当前功能

### 2.1 商城首页

- 展示平台名称和影片卡片。
- 示例影片覆盖会员或单片购买、会员专享、免费试看。
- 卡片展示标题、观看方式、价格与查看影片入口。

### 2.2 观看权益

| 类型 | 规则 |
| --- | --- |
| `free` | 所有用户可观看 |
| `subscription` | 有效会员可观看 |
| `purchase` | 已购买该影片的用户可观看 |
| `subscription_or_purchase` | 有效会员或已购买该影片均可观看 |

`canWatch()` 根据会员状态、已购影片列表与影片访问类型判定是否允许播放。

### 2.3 支付接口

支付层定义统一接口，计划支持 Stripe、微信支付与支付宝。统一订单包含订单号、金额、币种和支付渠道；各渠道需分别实现创建支付与支付回调验签。

### 2.4 播放授权

`/api/playback-token` 为播放授权接口占位。正式流程：验证登录、读取影片访问类型、校验会员或购买权益、生成短时效 Cloudflare Stream 播放令牌、前端使用令牌请求 HLS 视频流。当前接口未配置真实授权逻辑，返回 `501`。

### 2.5 数据模型

- `movies`：影片、售价、试看秒数和视频服务 ID。
- `orders`：支付订单与状态。
- `entitlements`：用户影片观看权益，来源为购买或会员订阅。

## 3. 环境变量

`.env.example` 包含 Supabase、Cloudflare Stream、Stripe、微信支付和支付宝的配置占位。禁止提交真实密钥。
