# HANABI 当前功能式样书（v4.0）

## 1. 项目定位
HANABI 是基于 Next.js、TypeScript、Supabase 与 Cloudflare Stream 的商城及正版影视平台。影片购买与实体商品购物流程彼此独立。

## 2. 全站导航
- 顶部导航提供影片、商城、收藏和个人中心入口，并集成影片搜索框。
- 商城悬浮购物车负责购物车入口，管理入口统一放在个人中心。
- 当前页面自动高亮并适配移动端。

## 3. 个人中心
- 采用共享左侧导航、右侧内容布局，手机端自动改为上下布局。
- 管理员可切换账户概览、影片管理和商品管理；非管理员只显示账户概览。
- 管理员权限由 `app_metadata.role = admin` 控制。

## 4. 影片功能
- 首页仅展示已发布且未软删除的影片。
- 首页采用参考 YouTube 的深色侧栏、顶部搜索、分类筛选和 16:9 影片卡片网格。
- 主页保持服务端组件，样式集中在 `app/globals.css`，不从服务端页面导入仅限客户端的 `styled-jsx`。
- 支持按标题或简介搜索，并按免费、会员、单片购买、会员或购买筛选。
- 登录用户可收藏或取消收藏影片，`/favorites` 展示个人收藏；未登录点击收藏跳转登录。
- 浏览器端 Supabase 客户端由 `lib/supabase-browser.ts` 统一创建。
- 支持免费、会员、单片购买、会员或购买四种观看策略。
- 付费影片直接创建单片订单，不进入购物车。
- 支持免费试看、播放授权、进度保存和断点续播。
- 视频来源支持 Cloudflare Stream 与 Supabase Storage 私有桶，接口签发临时播放凭证。
- 影片后台支持创建、编辑、草稿、发布、归档和可恢复软删除。

## 5. 商城功能
- `/shop` 展示已上架、未删除且有库存的商品。
- 商城右下角显示悬浮购物车按钮和实时商品数量。
- 商品详情支持价格、库存展示与加入购物车。
- 购物车支持数量调整、移除、合计和本地持久化。
- 结算支持 Stripe、微信支付、支付宝渠道选择；服务端校验价格和库存。
- 支付完成后更新商品库存，影片订单发放观看权益。

## 6. 商品管理
- `/admin/products` 支持商品新增、列表、编辑与软删除。
- 可维护名称、简介、图片 URL、价格、库存和上架状态。
- 状态包括草稿、已上架和已下架，历史订单保留。

## 7. 用户、订单与安全
- Supabase 邮箱注册、登录和会话管理。
- 管理员通过 `app_metadata.role = admin` 鉴权。
- 收藏表启用 RLS，用户只能管理自己的收藏。
- Webhook 使用签名校验完成订单、发放权益或扣减库存。
- Service Role Key、支付密钥和 Stream 私钥只能配置在服务端。

## 8. 数据库升级
- 全新环境执行 `supabase/schema.sql`。
- 已有影片环境执行 `docs/soft-delete-migration.md`。
- 商城功能执行 `docs/commerce-migration.md`。
- 双视频来源执行 `docs/video-source-migration.md`。
- 收藏功能执行 `docs/favorites-migration.md`。

## 9. 管理界面
- 影片表单显示明确标签，价格以元、试看时长以分钟输入并自动换算。
- 可选择 Cloudflare Stream 或 Supabase Storage 视频来源。
- 影片与商品表单采用响应式多列布局，简介独占整行，按钮居中。
- 管理页面不重复显示页面级大标题。
