# HANABI 当前功能式样书（v3.7）


## 1. 项目定位
HANABI 是基于 Next.js、TypeScript、Supabase 与 Cloudflare Stream 的商城及正版影视平台。影片购买与实体商品购物流程彼此独立。


## 2. 全站导航
- 顶部导航只提供影片、商城和个人中心入口。
- 首页内容区不再重复显示购物车和个人中心按钮；全站导航及商城悬浮购物车负责对应入口。
- 管理入口不在全站顶部展示，统一放在个人中心。
- 当前页面自动高亮，移动端支持横向滚动。


## 3. 个人中心
- 个人中心采用共享左侧导航、右侧内容的桌面布局，手机端自动改为上下布局。
- 左侧已移除“浏览”分组及影片首页、商城入口，仅保留账户概览和管理员功能。
- 管理员可从左侧切换账户概览、影片管理和商品管理，切换页面时左侧导航保持一致，当前页面自动高亮。
- 非管理员仅显示账户概览，管理功能根据 `app_metadata.role = admin` 控制显示。
- 账户概览显示当前邮箱、用户角色和退出登录按钮。


## 4. 影片功能
- 首页仅展示已发布且未软删除的影片。
- “正在热播”采用 YouTube 风格紧凑卡片网格，单卡宽度约 240–300px，缩略图比例为 16:9，影片数量少时不会拉伸占满整行。
- 支持免费、会员、单片购买、会员或购买四种观看策略。
- 付费影片在详情页直接创建单片订单，不进入购物车。
- 支持免费试看、播放授权、进度保存和断点续播。
- 视频来源支持 Cloudflare Stream 与 Supabase Storage 私有桶；播放接口根据来源签发 Stream Token 或 Storage 临时签名 URL。
- 影片后台支持创建、编辑、草稿、发布、归档和可恢复软删除。


## 5. 商城功能
- `/shop` 展示已上架、未删除且有库存的商品。
- 商城右下角显示悬浮购物车按钮和实时商品数量，点击进入 `/cart`。
- `/products/[id]` 展示商品详情、价格、库存和加入购物车按钮。
- 商品购物车支持数量调整、移除、合计和本地持久化。
- `/checkout` 支持 Stripe、微信支付、支付宝渠道选择并创建商品订单。
- 服务端以数据库价格和库存为准校验订单。
- 支付完成后更新商品库存；影片订单发放观看权益。


## 6. 商品管理
- `/admin/products` 支持商品新增、列表和编辑。
- 可维护名称、简介、图片 URL、价格、库存和上架状态。
- 状态包括草稿、已上架和已下架。
- 下架删除采用软删除，保留历史订单，并可通过修改状态恢复。


## 7. 用户、订单与安全
- Supabase 邮箱注册、登录和会话管理。
- 管理员通过 `app_metadata.role = admin` 鉴权。
- Webhook 使用签名校验完成订单、发放影片权益或扣减商品库存。
- Service Role Key、支付密钥和 Stream 私钥只能配置在服务端。


## 8. 数据库升级
- 全新环境执行 `supabase/schema.sql`。
- 已有影片环境先执行 `docs/soft-delete-migration.md`。
- 新增商城功能执行 `docs/commerce-migration.md`。
- 已有影片环境启用双视频来源执行 `docs/video-source-migration.md`。


## 9. 管理界面
- 影片表单显示明确标签，价格以元、试看时长以分钟输入并自动换算。
- 影片表单可选择 Cloudflare Stream 或 Supabase Storage，并分别配置 Stream UID 或私有桶及文件路径。
- 影片表单采用四/三/二/一列响应式布局，简介独占整行，操作按钮居中。
- 商品表单采用响应式布局，简介独占整行，创建、保存和软删除按钮居中。
- 影片管理和商品管理的右侧内容区不重复显示页面级大标题，直接进入创建与编辑区域。


## 10. 尚未实装
